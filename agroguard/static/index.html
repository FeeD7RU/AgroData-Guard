Как запустить локальную модель

Из папки проекта выполните в PowerShell:

.\start-local-agent.ps1

При первом запуске Ollama скачает Qwen3 14B (около 9,3 ГБ). Далее модель работает локально, без API-ключей и оплаты запросов.

Если Ollama уже установлена: ollama pull qwen3:14b, затем запустите проект обычной командой. Для менее мощного компьютера можно выбрать AGRO_LLM_MODEL=qwen3:4b.

Qwen работает локально через Ollama. Вопросы и измерения остаются на этом компьютере. API-ключ и оплата запросов не нужны.
